The macOS companion automatically discovers all chats available to your authenticated WebUI session. No context IDs or chat limit need configuring.

Separate subordinate chats keep their own identity and parent relationship. Agents working inside a chat appear as activity in that chat.

Requires configured WebUI login and CSRF protection; anonymous access is refused. Chat names are shared after known-secret masking. Names can still contain private information.

Plugin telemetry contains activity metadata, not messages, reasoning, tool arguments, or error details. The companion uses a session/CSRF-protected exact-target adapter for normal Agent Zero messages and pause/resume; missing chats are never created by these actions.

Global and effective project/profile plugin disablement are respected, including disabled ancestors. Old authorized-context and name-sharing settings are ignored by version 0.6.1.
